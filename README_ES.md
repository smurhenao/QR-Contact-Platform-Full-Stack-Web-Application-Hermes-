# 🕊️ Hermes — Plataforma de Gestión de QRs Dinámicos y Analíticas Pro

### 📌 Descripción General
Hermes es una solución **Full Stack (MERN)** diseñada para la creación, personalización y seguimiento métrico de códigos QR. 

A diferencia de un generador simple, Hermes ofrece un **ecosistema administrativo** que permite entender el comportamiento de los usuarios en tiempo real, optimizando la gestión de enlaces mediante datos precisos.

### 🚀 Características Principales

* **🎨 Branding Personalizado:** Generación de QRs con inserción de logos, manejo de transparencia y personalización de colores.
* **📈 Dashboard de Analíticas:** Visualización de datos mediante gráficas de rendimiento que muestran el flujo de escaneos por código.
* **🕒 Historial de Actividad:** Tabla de auditoría con registro exacto de fecha y hora de cada interacción.
* **💾 Exportación Profesional:** Lógica de renderizado en Canvas para descarga de archivos PNG de alta calidad.
* **🔐 Seguridad de Alto Grado:** Autenticación robusta basada en **JWT (JSON Web Tokens)** y protección de rutas en el Front-end.

### ⚙️ Configuración y Despliegue

1. **Clonar el repositorio**
   ```bash
   git clone [https://github.com/tu-usuario/hermes-qr.git](https://github.com/tu-usuario/hermes-qr.git)
Servidor (Backend)

Entra a la carpeta server: cd server

Instala las dependencias: npm install

IMPORTANTE: Crea un archivo .env en la raíz de la carpeta server con:

Fragmento de código

PORT=5000
MONGO_URI=tu_conexion_a_mongodb

Inicia el servidor: npm run dev

Cliente (Frontend)

Entra a la carpeta client: cd client

Instala las dependencias: npm install

Inicia la aplicación: npm run dev
